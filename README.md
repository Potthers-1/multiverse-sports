# Multiverse Sports

Gerenciador de campeonatos esportivos no navegador, pensado como um multiverso de competições e simulações.

## Estrutura

- Universos
- Temporadas
- Campeonatos
- Clubes
- Partidas
- Classificações
- Ramificações de realidade
- Simulações

## Rodar no navegador

Este repositório usa Vite + React + TypeScript.

```bash
npm install
npm run dev
```

O projeto também foi criado para continuar sendo desenvolvido pelo editor visual/browser-first do Floot.
